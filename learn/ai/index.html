Artificial Intelligence (DA §7)

Official: Search (informed, uninformed, adversarial); logic (propositional, predicate); reasoning under uncertainty — conditional independence representation, exact inference via variable elimination, approximate inference via sampling.

Objectives

Compare BFS/UCS/A*; state minimax with alpha-beta; convert to CNF; test entailment; factorize with conditional independence; run variable elimination order; describe rejection/likelihood sampling.

Key points

A* optimal with admissible + consistent heuristic. Minimax + alpha-beta prunes safely. Variable elimination cost dominated by largest factor. Sampling approximates posteriors when exact inference is intractable.
