Programming, DS & Algorithms (DA §4)

Official: Programming in Python; stacks, queues, linked lists, trees, hash tables; linear/binary search; selection/bubble/insertion sort; mergesort, quicksort; graph theory basics; traversals and shortest path.

Objectives

Trace Python code; compare sort/search complexities; run BFS/DFS and Dijkstra by hand on small graphs.

Complexities

Linear O(n), binary O(log n); selection/bubble/insertion O(n²); mergesort/quicksort-avg O(n log n); BFS/DFS O(V+E); Dijkstra O((V+E) log V) with heap.

Worked trace

def binary_search(a,x):
 lo,hi=0,len(a)-1
 while lo<=hi:
  m=(lo+hi)//2
  if a[m]==x: return m
  if a[m]<x: lo=m+1
  else: hi=m-1
 return -1
# a=[2,5,9,14], x=9 → m=1 (5<9, lo=2) → m=2 → return 2

Traps

Quicksort worst O(n²) on sorted input with naive pivot; stable vs unstable sorts; BFS uses queue, DFS uses stack.
