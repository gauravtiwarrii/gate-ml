DBMS & Warehousing (DA §5)

Official: ER-model; relational algebra, tuple calculus; SQL, integrity constraints; normal forms; file organization, indexing; data types and transformation (normalization, discretization, sampling, compression); warehouse modelling: multidimensional schemas, concept hierarchies, measures.

Objectives

Map ER→tables; write relational algebra + SQL; normalize to 3NF/BCNF; choose star vs snowflake; define roll-up/drill-down.

Key points

Keys: PK/FK enforce entity/referential integrity. Normal forms remove redundancy (1NF atomic, 2NF no partial, 3NF no transitive, BCNF every determinant a key). Index (B+ tree) speeds selection. Star schema: central fact + denormalized dimensions; snowflake normalizes dimensions.

Worked example

R(A,B,C), A→B, B→C. Key: A. Not 3NF (B→C transitive). Decompose: R1(A,B), R2(B,C).
