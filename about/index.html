Gaurav Tiwari — building GATE ML

I am Gaurav Tiwari, a computer-science/data-science builder. I started GATE ML on hellogaurav.me in October 2026 as an independent project: ML prep was scattered PDFs and quizzes that ignore real marking, so I built the sequence I wanted — guide, topic practice, timed mock, weakest-first review.

GATE ML is an independent, free study system for the Machine Learning portion of GATE Data Science & AI: a ten-unit study guide, 150 exam-pattern questions with worked solutions, flashcards, and a mock engine that marks like the real paper. No accounts, progress stays in your browser.

Mission: free, honest, offline-first ML prep. No paywall on core content, no fake stats. Next: opt-in Claude-powered hints grounded in our own guide — see Claude plan (planned, not yet built).
