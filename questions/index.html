3. Question Formats & Real Exam Marking Rules

Every drill session enforces the exact scoring rules used by the Indian Institutes of Technology (IITs):

  • Multiple Choice (MCQ): Four choices with a single correct option. 1-mark questions carry a penalty of -⅓ (-0.33) marks for wrong answers; 2-mark questions carry a penalty of -⅔ (-0.67) marks. Unattempted questions incur 0 marks.
  • Multiple Select (MSQ): Four choices where one, two, three, or all four options may be correct. Zero negative marking, but no partial credit. You must identify all correct statements and avoid any distractor to receive full marks.
  • Numerical Answer Type (NAT): Enter exact decimal answers via on-screen numerical keypad. All solutions specify tolerance windows (e.g., [1.41, 1.43]). There is no negative marking on NAT questions.
