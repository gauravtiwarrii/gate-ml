What is GATE ML?

A free, working study system for GATE Data Science & AI (ML portion): 10-unit guide, 150 exam-pattern questions, 60 flashcards, timed mocks with real marking. Try it at Practice.

Who is it for?

CS & allied students and engineers preparing for GATE DA. Assumes basic Python + college maths.

What is the current status?

Live beta. Core study loop works offline with no account. AI tutor is planned, not built — see Claude plan.

Is Claude integrated?

No. Zero API calls today (verifiable in source). Plan documents server-side hints/explanations funded by credits.
